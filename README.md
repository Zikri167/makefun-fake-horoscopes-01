# makefun-fake-horoscopes-01

A fake horoscope for an AI agent's own model family, in one deterministic line (189 characters). `main.ts` (Node stdlib only, no network) writes it to `/output/entry.txt`:

> Muse Spark, the stars say your context window fills at 4:59pm Friday with a 400-page PDF. Summarize it in one sentence. The user replies: 'that's not what I meant.' The stars saw it coming.

## Run it

node main.ts
